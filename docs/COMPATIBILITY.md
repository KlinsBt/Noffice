# Compatibility matrix

The authoritative target and completion procedure are now in the [desktop compatibility programme](parity/README.md). The descriptions below remain a current-capability audit. The programme retains incomplete commands and non-ribbon requirements, pursues explicitly tested browser equivalents and blocks exact-parity claims until evidence covers the complete scope.

Visible totals edits retain custom formulas and text labels in export; structured data sums exclude the totals row. Preset/extended totals activation, the totals dropdown and full toggling/movement remain incomplete. [Scope](EXCEL_TABLE_ENTRY.md).

Excel [direct entry below tables](EXCEL_TABLE_ENTRY.md) expands eligible ranges, updates calculated cells for literal input, activates a distinct totals row for formula input and keeps existing neighboring data outside the table. Paste/horizontal expansion, Tab insertion, preferences and complete inheritance remain open.

Calculated tables support [row-range growth and shrinkage](EXCEL_TABLE_RESIZE.md), with formula propagation into blank added cells, preservation of existing data/exceptions, explicit table qualification in excluded rows, master removal on full-column clearing, undo/reload and retained/new exports. Paste/horizontal expansion, full totals/column operations and full formatting/validation inheritance remain open.

Excel [direct table headers and international names](EXCEL_TABLE_HEADERS.md) support heading entry/Delete/paste, duplicate/blank normalization, simultaneous reference repair, atomic header/data edits and Unicode/backslash name calculation/export. Formula-to-header coercion, localized generated names, exhaustive Unicode equivalence and external/scoped/extension dependencies remain incomplete.

Excel [tables](EXCEL_TABLES.md) support creation with unique headers, row-range resizing, six styles and banding/emphasis options, filters, undo/reload and preserved exports. [Table/column renaming](EXCEL_TABLE_RENAMING.md) uses a dialog or direct header entry and repairs supported package references. [Calculated columns](EXCEL_CALCULATED_COLUMNS.md) fill/update eligible columns on direct formula entry, preserve exceptions and retain master formulas through undo, reload, rename and export. Full header coercion/localization, external/scoped dependencies, complete paste/autocorrect semantics, full totals operations, paste/horizontal expansion, column operations and complete styles/theme behavior remain open. Word hyperlink dialogs also capture immediate native selections before focus changes.

Whole-row/column insertion and deletion now support a retained worksheet subset, including formula/range/name repair, validation inheritance, formatting and saved undo checkpoints. Unsupported tables/charts/anchors/formula syntax are guarded. Eight actual browser stages have independent desktop Excel comparisons. [Scope and evidence](EXCEL_STRUCTURE.md).

Excel [data validation](EXCEL_VALIDATION.md) now has a dialog for whole/decimal/list/text-length rules, comparisons, input messages, Stop alerts and clearing rules. Blank cells use lazy imported ranges; formula bounds and surviving relative references have browser/package/native checks. Custom/date/time creation, Warning/Information flows and complete entry semantics remain open.

Excel [cell hyperlinks](EXCEL_LINKS.md) support address/label/ScreenTip editing, selection removal, undo/reload, web/email activation and supported internal cell/range/name navigation. Retained/new XLSX exports keep numeric/formula types; native Excel verifies the actual browser export. File/network destinations, HYPERLINK formulas, complete activation/protection behavior and full empty-range coverage remain open.

PowerPoint [solid outlines](POWERPOINT_OUTLINES.md) render on text, rectangles and ellipses with editable color, width, opacity, No outline and preset dashes. Supported line theme references resolve at import; new/retained exports carry text/shape outlines. Browser persistence/export and native solid/dash-dot checks pass. Custom strokes, compound/cap/join fidelity and complete line rendering remain open.

PowerPoint [solid fills and backgrounds](POWERPOINT_FILLS.md) now include text-box fills, shape no-fill, opacity, supported scheme colors/maps, style references and inherited backgrounds. Canvas, thumbnails, slideshow and new/retained exports carry the supported paints. Native tests cover 24 transform cases and the actual source/edited browser fixture. Gradients, complete theme/style inheritance and other paint kinds remain open.

PowerPoint [object layering](POWERPOINT_STACKING.md) supports all four ordering commands for represented single/multiple selections, with 248 native comparisons, saved reload and retained PPTX export evidence. Charts and other unrendered source objects remain real layers in the package. Group-child reordering, complete selection-pane behavior and rendering/editing of those opaque objects remain incomplete.

This document describes the current editable model, not desktop Office parity. The [downloaded 60-file corpus](OFFICE_CORPUS.md) adds external fixtures and selected Windows Excel/PowerPoint opening/rendering evidence. Full independent desktop validation remains open.

[Search and replacement](SEARCH_REPLACE.md) now covers Word text spanning formatting runs, Excel sheet/workbook/selection search with wildcard and value/formula options, and PowerPoint text occurrences across slides. It includes atomic protected/validated-cell rejection and retained-file browser export tests. Hidden Excel cells, advanced Word search and unsupported slide objects remain outside this coverage. Excel also exposes selected-range wrap and vertical alignment; automatic row fitting remains incomplete.

Excel calculation now includes tested absolute names, contiguous table selectors, INDIRECT, reference dimensions, error predicates, multiple criteria and scalar modern lookups. A 61-case native Excel oracle and 7,274 matching stored formulas in the structured-reference corpus provide bounded evidence. Dynamic spills, full table editing, relative named anchors, all function/format semantics and general desktop parity remain open. See [EXCEL_CALCULATION.md](EXCEL_CALCULATION.md), including the remaining audit discrepancies. Reopen older XLSX imports to load table metadata.

Newly imported DOCX/PPTX files export their original bytes when unchanged. DOCX patches supported paragraph, selected formatting and footnote edits into retained source parts; unsupported structural edits fail explicitly instead of rebuilding the document. PPTX patches supported existing text, direct formatting, geometry and notes, object/image additions and slide reordering into the retained package; unsupported imported structural changes fail explicitly. New presentations use the partial general writer. The 19 DOCX paragraph-addition loss cases now have no counted package/text/feature decreases. Preserved charts, masters, media and review structures are not thereby implemented in the browser editor. Reopen older imports to obtain new source metadata. See [Word preservation and limits](DOCX_PRESERVATION.md) and [PowerPoint preservation and limits](PPTX_PRESERVATION.md).

Typography now includes direct font family/size in all three modes, with basic DOCX/XLSX/PPTX typography round trips. DOCX export also carries script marks, paragraph line spacing, whole-document orientation and merged table spans. Bundled fonts work offline; system families require installation. Font binaries are **not** embedded in exports or native backups. See [FONTS.md](FONTS.md) for the exact supported behavior, missing scripts and font-portability limits. The task inventory is [TASKS.md](../TASKS.md).

## Word ribbon commands

[Word hyperlinks](WORD_LINKS.md) support web/email insertion at the cursor, applying links over mixed formatting, editing display text/targets and removing links, with separate undo, saved reload and new/retained DOCX export. The actual browser export passes installed Word destination and per-character formatting assertions before PDF rendering. Complete bookmark/file targets, ScreenTip editing and complex field/review structures remain open.

Word's additional Home/View/Review controls are scoped in [WORD_HOME.md](WORD_HOME.md). Character format painting, selected-text case changes, font stepping, indentation and display decorations have tests; browser word counts/spellcheck do not establish native Word proofing parity. The [complete Office 2016 catalog inventories](ribbon/README.md) retain unimplemented options, dialogs, tabs and contextual commands as unchecked acceptance work.

## Spreadsheet engine

Financial functions PMT, PV, FV, NPER, IPMT, PPMT, SLN, SYD, EFFECT and NOMINAL have 170 native Excel comparisons and a browser loan edit/undo/reload/cache-export workflow. See [EXCEL_FINANCIAL.md](EXCEL_FINANCIAL.md) for error/coercion scope, numerical tolerance and remaining financial functions.

Supported functions: VAR, VAR.S, VARP, VAR.P, STDEV, STDEV.S, STDEVP, STDEV.P, MEDIAN, LARGE, SMALL, RANK, RANK.EQ, RANK.AVG, PERCENTILE, PERCENTILE.INC, PERCENTILE.EXC, QUARTILE, QUARTILE.INC, QUARTILE.EXC, PRODUCT, GEOMEAN, HARMEAN, DEVSQ, AVEDEV, MODE, MODE.SNGL, SUBTOTAL, SUM, AVERAGE, MIN, MAX, COUNT, COUNTA, IF, IFERROR, IFNA, ISNA, ISERROR, ISERR, NA, ABS, INT, SQRT, ROUND, ROUNDUP, ROUNDDOWN, MOD, POWER, AND, OR, NOT, CONCAT, CONCATENATE, LEN, UPPER, LOWER, TRIM, LEFT, RIGHT, MID, EXACT, TEXT, VLOOKUP, HLOOKUP, XLOOKUP, XMATCH, INDEX, MATCH, COUNTIF, SUMIF, AVERAGEIF, COUNTIFS, SUMIFS, AVERAGEIFS, COUNTBLANK, ISNUMBER, ISTEXT, ROW, COLUMN, ROWS, COLUMNS, INDIRECT, DATE, YEAR, MONTH, DAY. Each has bounded scalar behavior; this list does not assert every Excel coercion, array, locale, or boundary case.

Supported syntax: arithmetic, comparisons, concatenation, percentage, parentheses, direct cells/ranges, absolute markers, quoted/unquoted sheet references, tested absolute names and contiguous table selectors, error literals and omitted arguments. IF, IFERROR and IFNA use lazy branches. Circular dependencies and exhausted resource limits fail explicitly.

VLOOKUP/HLOOKUP support exact and approximate matches, case-insensitive text and exact-match wildcards; INDEX/MATCH and XLOOKUP/XMATCH support tested scalar lookups. Dates remain serials with number formats and the imported 1900/1904 setting. A bounded numeric formatter and local SSF date/scientific adapter serve display and supported TEXT calculations. Format cells supports presets/custom codes with range application, preview, undo, persistence and XLSX style export. Its 55 native Excel cases and 370 external source caches match. Width-dependent fill/alignment, format colors, full locale/date semantics and TEXT coercion remain incomplete; see [NUMBER_FORMATS.md](NUMBER_FORMATS.md). Remaining financial/statistical functions, dynamic arrays, relative named anchors, locale-specific syntax, iterative calculation, and complete coercion/error semantics also remain open.

Unknown functions display `#UNSUPPORTED!`. IFERROR does not disguise unsupported calculations as ordinary fallback values. Export preserves original unsupported formula caches and requests recalculation; those cached values can be stale after inputs change. Genuine calculation errors and formula-returned strings such as `"#N/A"` are distinguished. Fill-down translates relative references. Imported sheet structure remains fixed pending full reference repair.

The 27 added statistical/product function names have 114 native Excel cases covering scalar values, reference coercion, errors, ties and interpolation. See [EXCEL_STATISTICS.md](EXCEL_STATISTICS.md); this is not the full statistical inventory.

Word paragraph indentation and print constraints have import/edit/export coverage in [WORD_PARAGRAPHS.md](WORD_PARAGRAPHS.md), with continuous browser editing and explicit limits for inherited hanging-style conversion. PowerPoint object rotation and image flips are editable and preserved; grouped, text/shape flip and other complex-transform behavior remains open.

SUM/AVERAGE/MIN/MAX/COUNT/COUNTA now have reference-aware coercion and error/empty-cell semantics verified by 128 native Excel cases. Supported INDEX row/column references and bounded large-range traversal are covered in [EXCEL_AGGREGATES.md](EXCEL_AGGREGATES.md).

## Imported XLSX preservation and editing

[Frozen panes](EXCEL_PANES.md) now support active-cell, top-row, first-column and unfreeze commands with undo, saved reload and retained XLSX output. The scrolling body remains virtualized with frozen rows. Actual frozen/unfrozen exports have been checked in native Excel. Split panes, boundaries crossing merges and complete native view behavior remain unfinished.

Filter range supports selected values, blanks, scalar comparisons and wildcard criteria. Reapply and clear operate on supported worksheet/table filters and participate in undo/save/export. Sheet settings exposes row hiding/unhiding with protection/filter guards. SUBTOTAL's tested operations account for persisted hidden/filter visibility and nested subtotal exclusions. Color/icon/date-group/dynamic/top-ten filters retain their existing visibility and original criteria, but cannot yet be reapplied through this editor. [EXCEL_FILTERS.md](EXCEL_FILTERS.md) documents the native validation and remaining limits. Reopen older imports to load filter metadata.

Unchanged export returns the original bytes. Supported cell/value/font/fill/alignment/number-format changes, custom row/column sizes, and sheet visibility changes patch source XML. Untouched ZIP entry payloads remain byte-identical, including themes, drawings, tables, comments, validation, names, external-link records, printer settings, and other retained parts. Formula-expression edits discard obsolete optional calculation-chain metadata and request full recalculation. Rich text runs and hyperlinks remain intact when their cell contents are untouched; mixed-run editing is not implemented. No external workbook is fetched.

The editor displays merges, hidden rows/columns, font families and sizes (1–409 pt), theme colors, basic indexed colors, borders, wrapping, vertical alignment, frozen panes, native date/number formats, notes and raster images. Theme tint rendering is approximate and the indexed-color palette is incomplete. Images are view-only; chart/pivot rendering, full print layout, conditional-format evaluation and advanced drawing editing remain open. Imported protected cells are locked in the UI unless the source marks them unlocked; password management and the full protection permission matrix are not implemented.

Literal and local named/range list validations supply choices. Stop rules cover lists and basic whole/decimal/date/time/text-length comparisons with literal bounds. Custom validation formulas, warning prompts, external/dynamic list sources and date-entry normalization are incomplete. General name creation/editing remains open; imported absolute names have the calculation subset described above.

Older saved XLSX imports lack source-part mappings and must be reopened from the retained original before using this export path. Unsupported structural modifications are rejected. Tests establish package preservation and selected browser behavior; Windows Excel screen/print validation has not been performed.

## Resource boundaries

- Imports: 30 MB compressed/input size; archive directory checks cap aggregate advertised expansion at 100 MB and individual entries at 32 MB.
- Workbooks: up to 10,000 imported rows and 256 columns per sheet; virtualized ordinary rows. Frozen-row views currently mount all visible rows and still need large-sheet performance work. Retained original package content outside the editable bounds is not evidence of full-grid editing support.
- Formula materialization and cell reads: bounded at 100,000 cells per calculation; recursive dependency depth is bounded. Reference dimensions and lazy lookups can use whole-column/row geometry, and the six core aggregates skip unused range tails; distant used cells and large traversals can still exceed the work limit.
- Raster image insertion: PNG/JPEG/GIF/WebP up to 8 MB.
- Native model validation caps sheet/slide/object counts.
- DOCX XML preflight caps nesting at 256 levels and 500,000 elements, rejecting DTD/entity declarations before recursive conversion.

These are defensive limits, not measured performance guarantees. Parsing still needs worker isolation, cancellation, and stronger malicious-archive memory bounds before handling hostile large inputs confidently.

## Storage and deployment

Files are local to the browser profile and origin. Saves are revision checked and versioned. Original Office bytes can be downloaded unchanged. Imported XLSX, DOCX and PPTX use the preservation paths described above; unsupported structural edits are rejected instead of falling back to reduced reconstruction. Use `.noffice` backups for the editable model and retained original.

Only static assets are deployed from `build/`. Service-worker installation requires HTTP localhost or HTTPS. Offline reopening is available after its initial asset cache finishes; updates activate after old controlled clients close.
