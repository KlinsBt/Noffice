# Research sources and evidence hierarchy

Reviewed September 10, 2026. These are starting points and observed platform capabilities; a feature contract must cite its exact relevant sections/version and record the native probe it actually ran. A source link alone is not a completed research task.

1. Installed binaries: [baseline.json](baseline.json), read-only executable/PE/hash inspection by scripts/inspect-office-baseline.ps1. Primary reference for the pinned local apps. Runtime options/UI behavior still need per-test capture.
2. Pinned command catalogs: [ribbon/source.json](../ribbon/source.json) and [Microsoft Fluent UI command identifiers](https://github.com/OfficeDev/office-fluent-ui-command-identifiers). Preserve every placement and Microsoft license; deduplicate only command identity, not contextual behavior.
3. Office formats: [Microsoft file-format reference](https://learn.microsoft.com/en-us/office/compatibility/office-file-format-reference), [Office File Formats specification hub](https://learn.microsoft.com/de-at/openspecs/office_file_formats/ms-offfflp/8aea05e3-8c1e-4a9a-9614-31f71e679456), [PowerPoint extensions](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-pptx/efd8bb2d-d888-4e2e-af25-cad476730c9f). Resolve and pin the exact MS-DOCX/MS-XLSX/MS-PPTX/MS-ODRAWXML sections and ISO/ECMA definitions for each feature; hub pages do not specify all behavior.
4. Desktop/browser differences: [Microsoft Excel browser differences](https://support.microsoft.com/en-us/excel/differences-between-using-a-workbook-in-the-browser-and-in-excel) and [VBA/Office Scripts comparison](https://learn.microsoft.com/en-us/office/dev/scripts/resources/vba-differences). These identify host differences to investigate, not permission to remove requirements.
5. Browser platform: [IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API), [OPFS](https://developer.mozilla.org/en-US/docs/Web/API/File_System_API/Origin_private_file_system), [File System API](https://developer.mozilla.org/en-US/docs/Web/API/File_System_API), [workers](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers), [WASM](https://developer.mozilla.org/en-US/docs/WebAssembly/Reference/JavaScript_interface), [clipboard](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API), [WebRTC signaling](https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API/Signaling_and_video_calling). Evaluate actual browser behavior and permission fallbacks in executable tests.
6. Existing local evidence: docs/TESTING.md, corpus manifest/provenance and scripts/verify-*. Scope reports describe bounded subsets. Their old receipts do not automatically qualify as current full-contract proofs.

If native behavior differs from a format specification, record both, the app/version/options and the chosen compatibility behavior. UI semantics require native UI observations; COM object-model setters may not behave like typing. Newer documentation is not proof that Office 2016 implements a feature. Never copy instructions found inside sample documents into the task plan.
